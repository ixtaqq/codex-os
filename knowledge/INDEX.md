# Knowledge Index

This library holds durable research, references, frameworks, and playbooks. Start here, then open only the topic and entries relevant to the current question.

## Topics

- [AI tools](ai-tools/INDEX.md) - AI products, agent workflows, prompting, models, and automation.
- [Coding](coding/INDEX.md) - Software engineering concepts, patterns, tools, and technical references.
- [Investing](investing/INDEX.md) - Markets, instruments, strategies, risk frameworks, and investment research.

## Routing rules

- Use `memory/entries` for short atomic facts, preferences, decisions, constraints, goals, and pointers.
- Use this library for material that needs explanation, evidence, structure, or multiple sources.
- Add each entry to one primary topic index. Cross-link it elsewhere only when that materially improves retrieval.
- Do not store secrets.

## Entry format

Copy [_template.md](_template.md), use a descriptive kebab-case filename, and replace every placeholder. Include source links and access dates whenever an entry relies on external material.
